# Добавление карточки

Карточки живут в приватном репозитории `yet-another-wolfgang-content`, путь к нему
берётся из `CONTENT_PATH` в `.env`. Одна карточка — один файл `cards/<id>.json`,
идентификатор равен имени файла.

## Ключевые принципы

**Теги внутри файла — единственный источник правды.** При отправке аудио по `file_id`
Telegram показывает метаданные закешированного файла и игнорирует параметры `title`
и `performer` из кода. Прикрыть неудачные теги на стороне бота нельзя.

**Спойлер убираем, атрибуцию сохраняем.** Вычищаются только поля, выдающие ответ.
Сведения о правах (`artist`, `comment`, `copyright`) остаются нетронутыми — это условие
лицензии используемых записей. Никогда не применять `-map_metadata -1`.

**Идентификатор неизменен.** На него ссылается прогресс пользователей в базе, поэтому
переименование файла осиротит накопленную статистику.

## Карточка без записи

Если записи пока нет, карточку всё равно стоит завести: она будет служить вариантом
ответа и начнёт задаваться вопросом сама, как только появится аудио.

```bash
python -m tools.add_card --id verdi-aida --title "Верди — «Аида»"
```

Это дешёвый способ наращивать разнообразие вариантов: название пишется за минуту,
а поиск и обрезка записи занимают куда больше.

## Карточка с записью

### Шаг 1. Проверить лицензию

Взять запись из источника со свободной лицензией: [Musopen](https://musopen.org),
[IMSLP](https://imslp.org), [Internet Archive](https://archive.org),
[classicals.de](https://www.classicals.de).

Выписать исполнителя и источник — они обязательны для карточки с записью.

Помнить про два слоя прав: произведение может быть в public domain, но конкретная
запись охраняется отдельно.

### Шаг 2. Выбрать фрагмент

Исходники обычно содержат произведение целиком. Разумная длительность — 30–40 секунд.
Начало берётся с `0`, если узнаваемая тема звучит с первых тактов; иначе нужно
уточнить у пользователя, какой именно эпизод брать.

Посмотреть, что в исходнике, можно так:

```bash
ffprobe -hide_banner -i "исходник.mp3" 2>&1 | grep -A20 Metadata
```

Тильда внутри кавычек не раскрывается — путь с ней пишется как `~/"Desktop/файл.mp3"`.

### Шаг 3. Добавить карточку

```bash
python -m tools.add_card \
    --id grieg-mountain-king \
    --title "Григ — «В пещере горного короля»" \
    --audio "~/Desktop/YAWolfgang/Grieg - In the Hall Of The Mountain King.mp3" \
    --start 0 --duration 35 \
    --fragment "В пещере горного короля" \
    --performer "Kevin MacLeod" --source "Musopen" \
    --fact "Первый факт." --fact "Второй факт." \
    --distractor tarrega-recuerdos
```

Инструмент вырежет фрагмент, снимет обложку и главы, поставит нейтральный заголовок,
загрузит файл в Telegram, заберёт `file_id` и запишет JSON. Ручного шага с пересылкой
файла боту не осталось.

Для загрузки нужны `BOT_TOKEN` и `ADMIN_CHAT_ID` в `.env`. Свой `chat_id` можно
узнать командой `/chatid` у бота.

Факты стоит подобрать заранее — за ними есть отдельный агент `fact-finder`.

### Шаг 4. Проверить и закоммитить

```bash
python -m tools.check_content
```

Покажет число карточек, список ожидающих записи и все проблемы: отсутствующие поля,
ловушки, ссылающиеся на несуществующие карточки, неполную атрибуцию.

Карточки коммитятся в репозиторий с контентом, а не в репозиторий бота.
