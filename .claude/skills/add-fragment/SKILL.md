# Работа с карточками библиотеки

Карточки живут в приватном репозитории `yet-another-wolfgang-content`, путь берётся
из `CONTENT_PATH` в `.env`. Одна карточка — один файл `cards/<id>.json`, идентификатор
равен имени файла и **неизменен**: на него ссылается накопленная статистика в базе.

## Три правила, которые не обсуждаются

**Лицензия проверяется до скачивания, а не после.** Права двухслойные: произведение
может быть в общественном достоянии, а конкретная запись — нет. Смотреть надо на тег
у файла, а не на страницу композитора.

**Теги атрибуции в файле не трогаем.** `artist`, `comment`, `copyright`, `license`
переносятся при перекодировании — это условие лицензий. `-map_metadata -1` запрещён.
Убирается только `composer`: он выдаёт ответ.

**Засечка записывается всегда.** Без `start` перерезать фрагмент потом можно только
по памяти, а память — плохое место для секунд.

## Что можно делать с лицензией

| Лицензия | Резать фрагмент | Что требуется |
|---|---|---|
| Public Domain, CC0 | да | ничего |
| CC BY, CC BY-NC | да | назвать лицензию в подписи (`--license`) |
| CC BY-SA | да | то же, плюс наша нарезка сама становится BY-SA |
| **CC BY-NC-ND** | **нет** | только файл целиком (`--as-is`) |
| EFF Open Audio License | да | не менять теги атрибуции |

**Non-PD US — это не лицензия, а география.** Пометка IMSLP о том, что в США
фонограмма ещё охраняется, хотя в Европе уже свободна. К тому, что нам разрешено
делать с файлом, отношения не имеет. Не путать с ND.

Источники: [Musopen](https://musopen.org), [IMSLP](https://imslp.org),
[Wikimedia Commons](https://commons.wikimedia.org), [classicals.de](https://www.classicals.de).
У Musopen и IMSLP лицензия своя у каждой записи — смотреть надо на файл, а не на сайт.

## Как выбрать засечку

Не на глаз, а замером. Карта громкости показывает границы фраз:

```bash
for s in $(seq 0 0.2 30); do
  v=$(ffmpeg -hide_banner -ss $s -t 0.2 -i "исходник.mp3" -af volumedetect -f null - 2>&1 \
      | grep max_volume | sed 's/.*max_volume: //;s/ dB//')
  printf '  %5.1f  %7s\n' "$s" "$v"
done
```

**Резать надо перед атакой, а не в неё.** Срез на пике первого аккорда даёт фрагмент,
который начинается сразу с полной громкости и звучит обрубленным. Целиться нужно
в провал перед фразой — он на 15–20 дБ ниже соседей.

**Подводка нужна там, где есть куда её положить.** Автоматика даёт 0.25 с всему, что
режется дальше двадцатой секунды, считая такой срез серединой произведения. Правила
хватает не всегда:

- музыка сплошная, провалов нет (остинато, вальс) — подводка единственный способ войти
  чисто, и её стоит удлинить до 0.5–0.6 с через `--fade`;
- срез в первые секунды, но музыка уже звучит — автоматика подводки не даст, а она
  нужна: ставить `--fade` руками;
- фрагмент открывается ударом из тишины — подводка убьёт атаку, ставить `--fade 0`.

Целиться лучше так, чтобы **подводка кончалась там, где входит фраза**.

**Громкость.** Если пик ниже −12 дБ, инструмент поднимает до −4, но не больше чем
на 10 дБ: выше вместе с оркестром вырастает зал и шипение ленты. Если он пишет, что
до уровня библиотеки не хватило, — это повод поискать место погромче, а не давить дальше.

Отдельная ловушка: если внутри фрагмента перепад больше 15 дБ (громкая медь, а следом
соло на пианиссимо), поднять его нечем — усиление считается по пику. Тихая половина
останется неслышной, и такой фрагмент лучше разделить надвое.

## Как найти потерянную засечку

У старых карточек `start` нет. Смещение восстанавливается корреляцией огибающих:
скачать фрагмент из Telegram по `file_id`, посчитать огибающие его и исходника
с шагом 20 мс, найти положение наилучшего совпадения. Корреляция выше 0.9 означает,
что смещение найдено верно.

## Команды

Карточка без записи — сразу пойдёт в варианты ответа, а вопросом станет, когда
появится аудио:

```bash
python -m tools.add_card --id verdi-aida --title "Верди — «Аида»"
```

Новая карточка с записью:

```bash
python -m tools.add_card \
    --id grieg-mountain-king \
    --title "Григ — «В пещере горного короля»" \
    --audio ~/"Desktop/Пакет с пакетами/YAWolfgang/Grieg - Mountain King.mp3" \
    --start 0 --duration 35 --fragment "В пещере горного короля" \
    --performer "Kevin MacLeod" --source "Musopen" --license "CC BY 3.0" \
    --description "Финал первой сюиты «Пер Гюнт»." \
    --fact "Первый факт." --distractor mussorgsky-bald-mountain
```

Перерезать один фрагмент, не трогая соседние, — **единственный правильный способ**
поправить звучание у многочастной карточки. `--update` затирает все фрагменты:

```bash
python -m tools.add_card --replace-fragment 0 --id saint-saens-introduction-rondo \
    --title "Сен-Санс — Интродукция и рондо каприччиозо" \
    --audio "..." --start 108.55 --duration 35 --fade 0.5 \
    --performer "Jonathan Vered" --source "Musopen"
```

Запись под NoDerivatives — целиком и без изменений:

```bash
python -m tools.add_card --as-is --id mascagni-intermezzo --title "..." \
    --audio "..." --performer "..." --source "IMSLP" --license "CC BY-NC-ND 4.0"
```

Тильда внутри кавычек не раскрывается: `~/"Desktop/файл.mp3"`.

## Тексты карточки

**Название: произведение впереди, часть после.** «Масканьи — «Сельская честь»,
интермеццо», а не «Интермеццо из «Сельской чести»»: на узкой кнопке хвост обрезается,
и произведение пропадает. Если карточек у одного произведения несколько, номер тоже
должен попасть в первые тридцать символов — «Концерт №2 для фортепиано».

**Имя фрагмента — только если добавляет к названию.** У карточки с одним фрагментом
различать нечего, и «Ноктюрн» при «Ноктюрн №2, Op. 9» — пустой звук.

**Описание продолжает название, а не начинает заново.** В подписи они склеиваются
через запятую, поэтому описание не должно повторять ни название, ни имя фрагмента,
ни содержание фактов.

**Факт самодостаточен.** Показывается один случайный, опереться на соседние он не
может. На описание — может: оно показывается всегда.

## Проверка

```bash
python -m tools.check_content
```

Показывает поломки, без которых библиотека не загрузится, и отдельно изъяны: повторы
между названием, фрагментом, описанием и фактами, сливающиеся при обрезке названия,
фрагменты без засечки, записи без лицензии. Изъяны ничего не блокируют — это список
для правки.

Коммитить карточки в репозиторий с контентом, а не в репозиторий бота.
